# L&T Financial Intelligence & Performance Analytics

A financial analytics project focused on analyzing L&T's financial performance, profitability, financial ratios, and shareholding structure using Excel, PostgreSQL, and Power BI.

## Project Overview

This project analyzes historical financial data of L&T across multiple financial years to understand financial performance and key business trends.

The analysis covers financial statements, profitability, financial ratios, standalone vs consolidated performance, and shareholding structure.

## Tools & Technologies

- Microsoft Excel
- PostgreSQL
- SQL
- Power BI

## SQL Analysis

The SQL analysis includes:

- Financial data exploration
- Data validation and quality checks
- Sales and Net Profit analysis
- Net Profit Margin analysis
- Operating Profit Margin analysis
- Standalone vs Consolidated comparison
- ROCE and RONW analysis
- Debt-to-Equity ratio analysis
- Cash Conversion Cycle analysis
- ROCE performance classification
- Shareholding analysis
- Analytical views for Power BI

## Power BI Dashboard

The Power BI dashboard provides insights into:

- Financial performance overview
- Balance Sheet, Profit & Loss and Cash Flow
- Sales and Profitability trends
- Financial ratio analysis
- Standalone vs Consolidated performance
- Shareholding structure

## Project Workflow

1. Prepared and organized financial data using Microsoft Excel
2. Loaded the prepared data into PostgreSQL
3. Performed data validation and quality checks
4. Analyzed financial statements using SQL
5. Calculated profitability and financial ratios
6. Compared Standalone and Consolidated performance
7. Created analytical views for reporting
8. Connected the analysis to Power BI
9. Created interactive financial performance dashboards

# L&T Financial Intelligence & Performance Analytics

## Project Overview

This project analyzes L&T financial performance using historical financial data and presents key insights through SQL analysis and Power BI dashboards.

## Objective

The objective of this project is to analyze financial performance, profitability, financial ratios, and shareholding patterns across multiple financial years.

## Tools & Technologies

- Microsoft Excel – Data Preparation
- PostgreSQL – Data Analysis
- Power BI – Dashboard & Visualization

## Project Workflow

Excel → PostgreSQL → Power BI

### 1. Data Preparation
Financial data was prepared and organized using Microsoft Excel.

### 2. SQL Analysis
PostgreSQL was used to analyze financial data including:

- Sales and Net Profit
- Net Profit Margin
- Operating Profit Margin
- Standalone vs Consolidated performance
- ROCE and RONW
- Debt-to-Equity Ratio
- Cash Conversion Cycle
- Shareholding structure

### 3. Power BI Dashboard
The analyzed data was used to create an interactive financial performance dashboard covering:

- Financial Overview
- Financial Statements
- Financial Ratios & Shareholding
